Party Prep Tracker

The app allows users to store party supplies online and gives them a detailed shopping list.


Features

Enter your item
Add your item to the list
View the list
Go back to the homescreen


Installation Instructions

1. Clone the repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Run the application on an emulator or Android device.


Usage

Enter party item.
Click the button to add item to list.
Click the button below to view the shopping list.
Click the button at the bottom of the list to go back to the Homescreen.
